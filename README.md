# PBI-biggish-data

This repo is a proof-of-concept for low code / no code data science. The objective
is to apply simple data science methods to a large dataset (> 12 million records) using a 
combination of SQL Server and Power BI.. 

The data source is BioTIME, the global biodiversity dataset which contains over
12 million records. Please see the following link for more information about BioTIME.

https://biotime.st-andrews.ac.uk/

This repo contains T-SQL scripts and Power BI files to *should* be executable. These
examples are for education purposes only. Please re-use them at your own peril.
